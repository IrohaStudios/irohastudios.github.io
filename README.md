# Iroha Studios 主页

目标仓库：`IrohaStudios/irohastudios.github.io`

目标网址：https://irohastudios.github.io/

静态 HTML + CSS，无构建步骤、第三方脚本或远程字体。支持手机布局、键盘导航和减少动态效果偏好。

## 发布

1. 在 GitHub 新建公开仓库，Owner 选择 `IrohaStudios`，仓库名为 `irohastudios.github.io`。
2. 将本目录中的 `index.html`、`style.css`、`favicon.svg` 和 `.nojekyll` 提交到 `main`。
3. 在仓库 Settings → Pages 中选择 Deploy from a branch，分支 `main`，目录 `/ (root)`，保存。
4. 等待 Pages 构建成功，检查目标网址。

文档：https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 内容与设计

首版只包含已知团队名称、公开 GitHub 入口和主页欢迎语。团队成员、项目介绍及联系邮箱等待真实资料后补充。

视觉参考：Co Projects（https://co-projects.xyz）的白底、黑字、大标题、直角和细分隔线；Aaron Poe & Co（https://aaronpoeandco.com）的简洁文字布局及可读行高。只借用排版原则，使用原创页面结构和系统字体，无外部设计素材。
