# 大肥鱼嘴型参数修复

2026-11-01：用户反馈播放音频时角色不张嘴。

根因：适配器把普通字符串传给 Cubism 的 `setParameterValueById`，该 SDK 需要内部 ID 对象。字符串被视为不存在的参数，写入虚拟索引，实际嘴巴参数未变化。修复前实测 `ParamMouthOpenY` 的真实索引为 36，字符串查询返回模型实际参数数量之外的 263；音频播放时请求值约 0.55，实际值仍为 0。

改为使用已从模型取得的真实索引调用 `setParameterValueByIndex`。保留原有音频时间轴、嘴型插值和参数范围限制；生成页面更新脚本哈希。

验证：Chromium + SwiftShader 中播放喜怒哀惊四段音频，在 `beforeModelUpdate` 读取真实参数数组，逐帧与目标值一致且存在张嘴帧；暂停归零，进度跳转跟随媒体时间。冻结其他动画分别渲染闭嘴／张嘴，已查看截图确认实际嘴部形变。无脚本异常。证据：`/data/ly/outputs/iroha-lipsync-fix-20261101/`。
