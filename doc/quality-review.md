# 三套规则的主页检查记录

2026-10-31。用户要求将现有主页按 Humanizer-zh、Impeccable 和 Taste Skill 各检查一遍。范围是现有主页的文案、版式和交互细节；继续使用已确定的冷蓝科幻二次元主视觉、选定头像和 Apple 系统字体栈。

## 使用的规则与工具

- [Humanizer-zh / SKILL.md](https://github.com/op7418/Humanizer-zh/blob/main/SKILL.md)：读取 2026-09-23 修订版，逐段检查中文文案，核对事实、范围和链接。
- [Impeccable / SKILL.md](https://github.com/pbakaus/impeccable/blob/b7a89176e4e87422b40f98adabceb051dbb5448b/.agents/skills/impeccable/SKILL.md)：读取 audit、polish 和 craft-floor；实际运行 `context --target index.html` 以及对 HTML、CSS、浏览器页面的 `detect --json`。版本 4.8.0。
- [Taste Skill / SKILL.md](https://github.com/Leonxlnx/taste-skill/blob/12af471f627f866411b4bd785b19646d3672784c/skills/taste-skill/SKILL.md)：读取既有页面流程、文案和截图评审规则；实际运行 `lint.mjs` 与 `inspect.mjs`，对照修改前后 1440、768、390px 的首屏及整页截图。

本轮是在既定视觉内做检查与修正，没有重新抽取风格方向或随机种子。检查工具放在独立工具目录，没有增加页面运行时依赖、全局 hook 或自动安装规则。

## Impeccable：处理可核实的问题

- 取消标题上方的英文小标签、装饰性编号、重复式小标题、静态硬阴影、装饰渐变和头像轨道。图片遮罩仅用于保证文字可读。
- 正文采用 16px，首屏说明在桌面使用 18px；辅助文字至少 13px。保留正文 500、操作 600、标题 700 的字重。
- 操作图标统一为相同笔画的 SVG；试听按钮保留清楚的中文情绪名称。
- 情绪按钮至少 44px 高；音频进度条扩大触控区域。补齐按钮按下状态、可见焦点和选中文字的配色。
- 页脚文字对比度从检查器指出的 4.46:1 提高到浏览器计算的 5.01:1。
- 两项静态 `cramped-padding` 指向通栏 hero 和 research 背景；浏览器核实内容有独立内层留白。1440px 下项目、研究、关于区域的左右外边距均为 89.28px，属于静态扫描误判。

技术复核评分是人工判断，不是工具自动评分：可访问性 3/4、性能 3/4、主题一致性 3/4、响应式 4/4、实现一致性 3/4，总计 16/20。仍保留部分既有颜色常量和较大的原始插画资源；没有把本轮检查称为完整 WCAG 认证。

## Taste Skill：结果与保留项

| 指标 | 修改前 | 最终 |
| --- | --- | --- |
| 渲染检查 FAIL 类别 | 12 | 0，明确豁免 `few-pictures` 一项 |
| 渲染检查 WARN 类别 | 5 | 3，逐项说明如下 |
| 桌面实际文字字号数量 | 16 | 7 |
| 小于 13px 的正文区文字块 | 21 | 0 |
| 大写、宽字距小标签 | 15 | 0 |
| 标题最大行数 | 2 | 2 |
| 三种检查宽度横向溢出 | 无 | 无 |

`few-pictures` 要求至少四张较大的图片。实际页面由原创主视觉、研究博客预览、真实试听界面和用户头像组成；检查器将 SVG 容器中的用户原始位图排除在图片计数外。最终检查使用 `--allow few-pictures`，没有为凑数量添加无关图片。原始未经豁免的修改后检查仍报告这一项，不能称为完全无条件通过。

保留的三项 WARN：

- `no-footage`：页面以声音试听为核心，现有主视觉已支持轻量视差，没有加入无关自动播放视频。
- `off-centre`：工具以文字末端的分位数估算外边距，SVG 箭头不计入文字范围；真实内容容器左右边距相等，已测量并查看截图。
- `name-only-title`：工具用空格词数或单段文字不少于 36 字判断是否说明用途，不能可靠覆盖被换行分开的中文说明。首屏明确写出“Iroha-TTS”“可控语音模型”，并有“试听 Iroha-TTS”操作。

源码 lint 仍会标出正常文档流中的阅读遮罩、音频控件边框、零波形细线和时钟补零。这些需要结合渲染结果解释，不通过改名或隐藏内容消除扫描结果。Apple 系统字体是用户明确选择，不按工具的其他字体偏好替换。
