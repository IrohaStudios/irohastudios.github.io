Iroha Studios について

私たちは Iroha-TTS を開発し、合成音声の感情、ささやき、笑いなどの発声表現の制御を研究しています。

モデルは Hugging Face で公開し、学習手法、試聴サンプル、試行錯誤の記録は研究ブログにまとめています。今後のリリースは GitHub と Hugging Face でご確認いただけます。
